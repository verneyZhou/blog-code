## 1. 硬事实清单（写作时必须准确）

> 原则：**宁可模糊，不可出错。** 拿不准时用"约""数千亿"这类安全表述，绝不编造精确数字。

### 宇宙学与天文

| 事实 | 正确表述 | 易错点 |
|---|---|---|
| 宇宙年龄 | 约 138 亿年 | 别写成"宇宙直径 138 亿光年" |
| 可观测宇宙直径 | 约 930 亿光年 | 口径 ≠ 年龄；膨胀使可观测尺度大于光行距离 |
| 银河系恒星数量 | 约 1000–4000 亿颗（用"数千亿"更稳） | 别写"数万亿" |
| 地球年龄 | 约 46 亿年 | — |
| 原核 → 真核 | 约 20 亿年前（用"约"） | 别精确到具体年份 |
| 最近恒星系 | 半人马座 α，约 4.37 光年 | 别写"一光年外" |
| 微波背景辐射 | 宇宙约 38 万年时的"婴儿照" | 不是"宇宙诞生时的照片" |
| 光速 | 299,792 km/s | 真空光速，别在介质中混淆 |
| 精细结构常数 α | 约 1/137 | 若引用"时变争议"，必须标注"未定论" |

### 物理与工程

| 事实 | 正确表述 | 易错点 |
|---|---|---|
| 量子芝诺效应 | 反复观测冻结量子态（已验证） | 是真实效应，别写成"假说" |
| 香农信道容量 | C = B·log₂(1+S/N) | 只讲概念，不必给公式；别混淆"信息量"与"信号强度" |
| Landauer 原理 | 擦除 1 bit 信息至少耗能 kT·ln2 | 概念可用，别精确到具体数字场景 |
| 引力波 | 2015 年 LIGO 首次直接探测 | 别把"引力波"与"重力异常"混为一谈 |
| 大撕裂 | 需要暗能量状态方程 w<-1，当前观测不支持 | **必须**由角色强调"这是假设" |
| 超新星 | II 型核心坍缩 / Ia 型白矮星吸积 | 别把 Ia 型写成"恒星死亡"的通用形态 |
| 红移 | 距离越远红移越大 | 别把红移写成"光变色"的通俗错误 |
| 射电望远镜 | 观测窄带信号、用阵列提高分辨率 | SETI 流程须写实：先排除人为/天体干扰 |

### 时间线（避免穿越式错误）

| 事件 | 年份 | 备注 |
|---|---|---|
| 跨大西洋无线电 | 1901 年（马可尼） | 人类"技术文明"的时间锚点 |
| SETI 正式起步 | 1960 年（奥兹玛计划） | — |
| 系外行星首次发现 | 1992–1995 年 | 别写成 1980 年代 |
| LIGO 首次探测引力波 | 2015 年 | — |
| 詹姆斯·韦布望远镜发射 | 2021 年 | 文中若提及须对 |
| 五角大楼 UAP 报告 | 2023 年起公开 | 若借时事须表述准确 |

## 2. 常见翻车点规避（写作红线）

### 绝对不写（低级错误）

- [ ] 真空中出现"音爆"（真空中无介质传声）
- [ ] 望远镜"看到外星人脸上的表情"（分辨率和角秒限制）
- [ ] "飞船瞬间穿越"违反光速极限而不作任何设定解释
- [ ] 单位换算错误（光年/天文单位/秒差距混用）
- [ ] 行星"刚好在宜居带就有生命"（宜居带 ≠ 宜居，金星是反例）
- [ ] 恒星"燃尽"描述成"像煤烧完"（核聚变 ≠ 燃烧）
- [ ] 时间线穿越（如 1980 年代出现韦布望远镜数据）
- [ ] 把"红移"写成光在传播中"变红褪色"（是多普勒/膨胀效应）

### 必须写清（争议假说）

- [ ] 大撕裂：必须有角色说"当前观测不支持，只是假设"
- [ ] 精细结构常数漂移：必须有角色说"这是未定论争议"
- [ ] 目的场（全书唯一虚构引擎）：必须有角色说"这不属于已知物理"
- [ ] 理解力额度：必须有角色说"这只是个比喻"

## 3. 语言与肌理纪律（全书的"人味"保障）

> 核心原则：**科学是底色，不是外衣。** 读者要的是"县城里的宇宙"，不是"宇宙里的县城名词堆砌"。

### 3.1 每个科学概念，必须翻译成"县城语言"

| 科学概念 | 正例（许明/老周口中的说法） | 反例（炫技） |
|---|---|---|
| 轨道根数反推 | "我按它报的位置，反着把轨道倒推回来" | "用高斯法反解轨道六要素" |
| 精细结构常数 | "那个数字，几百年没人解释得清，现在它自己动了" | "α 的一阶时间变分出现了可观测偏移" |
| 量子芝诺效应 | "你越盯着它看，它越不敢动——像被班主任盯着的学生" | "频繁测量导致波函数坍缩概率流被冻结" |
| 香农信道容量 | "宇宙像一根水管，水就那么多，你喊得越响，听清的越少" | "信道容量随信噪比的对数关系指数恶化" |
| 事件视界 | "掉进去的东西，永远传不出一个字" | "de Sitter 视界处信息不可逆丢失" |

**规律**：每个专业词进场前，先找一个"县城的比喻"；比喻没有找到，这个词不进正文。

### 3.2 用动作和物件代替概念

- 不写"他在分析频谱"→ 写"他把耳机音量拧到最小，听那段信号的呼吸"
- 不写"盖革计数器计数率偏斜"→ 写"那台仪器滴滴声突然密了，像雨点砸在铁皮上"
- 不写"人类共同体震动"→ 写"楼下卖早点的王婶都在问：今晚还停电吗"

### 3.3 科学名词密度上限

- 每章出现的"专业名词"**不超过 3 个**，且每次出现必须有比喻/动作承接
- 名词第一次出现=解释，第二次出现=复用，第三次出现=可以作为日常（读者已经学会了）
- **永远不让读者查字典**：读者一旦停下来查"这是啥"，震撼就断了

### 3.4 真诚的四个来源

1. **动机在场**：每个角色做每件事，读者都能在上一章找到他为什么这么做
2. **代价可见**：老周每一次接近真相，都失去一样东西（安稳、职业、女儿的理解）
3. **细节是县域的**：泡面、晚自习的粉笔灰、批改到深夜的红笔、县城中学特有的"一个人兼天文社老师"
4. **情感落点是小人物**：宇宙的真相最终落在"一个父亲把答案写给五十个孩子看"

### 3.5 转折与结尾的纪律

- **转折必须"既意外又必然"**：回头重读，每一处反转都能在更早的章节找到伏笔
- 结尾的震撼来自"读者自己想到的"，不是"作者硬塞的"——**写到八九分，留一分给读者合上**
- 神之结尾的三条标准：① 回收所有伏笔（包括"不存在的学生"）；② 反转不依赖新设定（用已有机制）；③ 读者合上书后，第一反应是"重读一遍找伏笔"

## 4. 科学名词使用守则

1. **每处科学名词都能在 [01-设计总览.md](01-设计总览.md) 的科学基准表里找到归属档位**，找不到就不写。
2. **已确立物理**（牛顿力学、麦克斯韦、广义相对论、量子力学基础）必须零错误。
3. **争议假说**（α 漂移、大撕裂、测量问题）允许使用，但必须在文中标注其争议地位。
4. **虚构引擎**（目的场）全书只有一次，必须由角色"自我怀疑"来承认它超出已知物理。
5. **不确定就模糊**：拿不准的数字用"约"，拿不准的机制用"尚未知"，绝不硬编。

## 5. 核查流程（每章完成后）

```
□ 1. 对照硬事实清单，逐条检查文中的数字/事件/年份
□ 2. 检查所有科学名词：能在科学基准表里定位吗？
□ 3. 检查争议假说：有没有角色"说破"它的争议地位？
□ 4. 检查虚构引擎：全书是否只出现一次目的场？有没有多买？
□ 5. 反问：如果一位天体物理系研究生读这章，会在哪里皱眉？
□ 6. 若皱眉点存在——要么修正，要么让角色把"未确定"说出来
□ 7. 语言检查：本章专业名词 ≤3 个？每个都有县城比喻/动作承接？
□ 8. 动机检查：本章每个角色的每个行为，上一章都能找到"为什么"
□ 9. 转折检查：本章若有关键反转，它的伏笔在更早章节埋好了吗？
```

---

## 6. 最后提醒

> 真实物理负责让读者信服，半步虚构负责让读者震颤——**中间隔着的那条线，全程用红笔标着。**
> 读者的拆穿不可怕，可怕的是拆穿后发现我们"不知道自己不知道"。
> 这张清单存在的意义，就是让"不知道"的部分在落笔前先显形。
> 而最重要的那条：**科学让读者相信，人味让读者流泪，转折让读者惊醒——三者缺一，都不是你要的颅内震撼。**
